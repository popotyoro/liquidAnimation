# 配布までの残作業

飲水・飲酒ログアプリで利用できる液体表示のSwift Packageを配布する。アプリ本体の機能はこのプロジェクトに含めない。表示の仕様は[液体注入アニメーション仕様書](liquid-animation-spec.md)を参照。

## 直近のゴール

液体表示ライブラリをSwift Package化し、このデモアプリからリンクして利用できるようにする。

- [ ] 液体表示・設定・操作APIとMetalリソースをSwift Packageへ切り出す。
- [ ] デモアプリにそのパッケージをリンクし、パッケージ経由で液体表示を利用する。

## 配布に向けた整備

- [ ] 導入例と対応OSを記載する。
- [ ] 実機で追加注水・触覚・画面復帰・カレンダー再表示と目立つ処理落ちを確認する。
