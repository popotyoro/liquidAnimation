# 液体注入アニメーション仕様書

## 目的と表示

任意の画面を長方形の容器に見立て、上端の一か所から液体を斜めに注ぐ。文字・画像・ボタンは障害物として扱わず、水のレイヤーを重ねる。背後の画面は透けて見え、タッチ操作を妨げない。

- SwiftUI の iOS アプリ。最低対応バージョンは iOS 27.0。
- 正面から見た2D表示。重力は画面下向きに固定する。
- 量と不透明度を0〜100%で設定できる。
- 連続した水流、着水時の飛沫と波、横への広がり、注水後の減衰を表現する。
- 最近の iPhone で60fpsを目標とする。達成の判断には実機測定を使う。
- 開発時の実行先は iPhone 18 Pro。iPhone Duo は使用しない。

## 液量は空中の水も含めて管理する

%は容器の容量に対する投入総量を表す。空中の水流・飛沫も投入量に含め、目標に達した時点で流入を止める。その後、空中にある分が着水して水面が落ち着くと、50%なら容器の中央が平均水位になる。

一定の奥行きを仮定し、2D断面の面積で管理する。容器の幅を `W`、高さを `H`、水深を `h(x)` とすると、容量と保存する量は次のとおり。

```math
A_{capacity}=WH,\quad
A_{emitted}=A_{jet}+A_{spray}+A_{pool},\quad
A_{pool}=\int_0^W h(x)\,dx
```

目標量を超えて追加しない。水面の波で局所的に中央を超える場合も、平均水位と投入量を区別する。境界での丸めやクリップによる誤差は、水深を0〜Hに保つ補正で取り除く。

## 設定と操作

| 項目 | 範囲・初期値 |
| --- | --- |
| 目標量 | 0〜100%、初期値50% |
| 不透明度 | 0〜100%、初期値45%。0%では水を表示しない |
| 注ぐ位置 | 上辺の15〜85%、初期値25% |
| 注ぐ角度 | 鉛直下向きが0°、−65〜65°、初期値30°。正の値は右向き |
| 流量 | 毎秒、容量の2〜16%。初期値8% |

「注ぐ」で空の状態から指定量まで注ぐ。流量設定は最大流量を表し、開始・終了時は滑らかに増減する。一時停止・再開・空に戻す操作を用意する。不透明度は即時反映し、それ以外の設定は次の注水から適用する。注水終了後も水面の計算を続ける。画面サイズが変わった場合は空に戻す。

試作画面には透過を確認する文字・図形・ボタンを配置する。操作パネルを重ねても液体の描画領域を縮めない。

## 落下水流と浅水モデルを組み合わせる

粒子方式の試作で生じた玉状の輪郭、強い跳ね返り、水位誤差を改善するため、現在は**重力による落下水流と、連続した水面の計算**を組み合わせる。液体内部の渦を含む2D Navier–Stokes方程式を全面的に解く方式とは異なる。

### 落下水流

初速と重力から軌道を計算する。細かい時間区間ごとに投入時刻と量を記録し、軌道が水面または底に達した分を容器内の水へ移す。壁では外へ抜けず、壁沿いに下へ流す。壁から弾性反射させない。

```math
x(t)=x_0+v_{x0}t,\qquad
y(t)=v_{y0}t+\tfrac12gt^2
```

描画は一続きの帯とする。流量を `Q`、落下速度を `|v|` とし、帯の幅は `Q/|v|` から求める。水流が加速すると細くなり、注水を止めると末尾が落ちて消える。先端は残っている最古の水の位置から水面まで最大約33ms分補間し、時間刻みによる着水点の隙間を抑える。入口の断面を画面内に見せないよう、帯を画面上方まで延長してクリップする。開始・終了時は最大0.25秒かけて流量を増減し、その履歴から帯の各位置の幅を求める。最後は上側から細くなって切れ、残った水が落ちる。開始・終了の細い部分には追加の描画点を置く。表面張力による分裂は未計算。

最大流量を `Q`、目標面積を `A` とすると、増減時間は `r=min(0.25, A/Q)`、注水時間は `T=A/Q+r`。増加区間は `Q(3u²−2u³)`（`u=t/r`）、減少区間はその時間反転を使う。面積はこの関数の解析的な積分で求め、細かい時間刻みでも総量を指定値に合わせる。少量指定では増加区間と減少区間がつながる。

投入時刻に応じた二つの正弦波で帯を揺らし、太さも変える。変形は落下中に育つ描画上の近似であり、乱流や表面張力を解いてはいない。液量と着水位置の判定には元の放物軌道を使う。

### 着水時の飛沫と跳ね返り

着水点に水深と上方の空間がある場合、最大約40回/秒、各2滴の飛沫を出す。その時間刻みの着水量の32%を飛沫へ振り分け、残りを水面に加える。飛沫は投入量に含まれ、追加の水は生成しない。飛沫の同時数は最大96滴。上昇速度は最大1.15m/s（静止水面から約6.7cm上昇）に制限する。

飛沫は重力で落下し、壁では水平速度を15%に減らして反射する。落下中に水面に触れると全量を戻し、再び飛び出させない。描画は速度方向に伸ばした楕円とし、面積を保ったまま縦横比を変える。着水時には水面へ外向きの運動量を加えて波を作る。これらは見た目と計算量を調整した近似で、厳密な飛沫生成モデルではない。

### 容器内の水

垂直方向を平均化し、水平1次元の浅水方程式で水深 `h` と流量 `q=hu` を計算する。`u`は横方向の速度、`g`は重力加速度。

```math
\frac{\partial h}{\partial t}+\frac{\partial q}{\partial x}=s_h,\qquad
\frac{\partial q}{\partial t}
+\frac{\partial}{\partial x}\left(\frac{q^2}{h}+\frac12gh^2\right)
=s_q-\gamma q-h\frac{\partial P}{\partial x}
```

着水量を局所的に加え、横への広がりと波を計算する。さらに、落下水流の鉛直運動量から外部圧力 `P=p/ρ` を近似し、水面を押し下げる力 `−h ∂P/∂x` を運動量に加える。圧力は着水点を中心としたガウス分布とし、積分値は着水面積×鉛直速度から求める。圧力によって中心から水が押し出され、へこみと両脇の盛り上がりが生じる。これは水深を直接削る処理ではなく、総量を保つ移動である。

圧力への結合係数は0.12、水頭の上限は6cm、応答時間は60msとする。分布の標準偏差は2.5セル幅または水流幅の65%の大きい方を使い、未解像の鉛直運動を安定した浅水モデルへ近似する。注水終了後は圧力を減衰させ、へこみも自然に戻る。着水時の小さな外向きの運動量を近似的に加える。壁は反射境界とし、壁を通過する液量をゼロにする。運動量の減衰と数値的な拡散により波を静める。

128列の有限体積法と Rusanov flux を使い、CFL条件に応じて時間刻みを分割する。容器の幅は0.75m、重力は9.81m/s²、初速は1.6m/sと仮定する。処理が遅れた場合に大量の追いつき計算は行わない。

波の巻き返り、砕波、大量の独立した飛沫、気泡、厳密な粘性・表面張力は対象外。水面は各水平位置につき一つの高さで表す。これは軽さと安定性を優先するための、合意済みの簡略化である。

## SwiftUI・CPU・Metalの役割

SwiftUI は背景画面・設定・操作を担当する。CPU は水流・飛沫の軌道、液量、水深と運動量を計算する。Metal は水面・水流の帯・飛沫を描画し、半透明の着色と連続した水面のハイライトを重ねる。液体全体を粒子に置き換える処理や、GPUで圧力を反復計算する処理は使用しない。

`MTKView` を `UIViewRepresentable` で組み込む。毎フレームの水面データを SwiftUI の状態へ渡さず、計測表示は約0.5秒ごとに更新する。設定画面には描画頻度、GPU時間、物理計算のCPU時間を表示する。

アプリとテストは Swift 6 の言語モードと厳格な並行性チェック（complete）を使用する。UI、水面モデル、CPUによる描画バッファの書き換えは MainActor 上で行う。Metal の完了通知では計測値とエラー文字列を取り出し、MainActor のタスクへ渡す。前のGPUコマンドが完了するまで次のフレームのバッファを書き換えない。

背景をゆがめる屈折には背景画像を渡す設計が必要なため、初期版では扱わない。

## 検証

本体を変更した後は、先に `LiquidAnimation` スキームで `BuildProject` を実行し、続いて `LiquidAnimationTests` スキームを iPhone 18 Pro で実行する。現在のテストホストの依存関係は自動解決されず、テストだけの実行では古い本体を参照し得る。ビルド・テスト・実行には Xcode MCP を使い、`xcodebuild` やDuoを選ぶ可能性があるプレビュー経由の検証は使わない。

- 0%・50%・100%の投入総量、着水量、静止後の平均水位が一致する。
- 注水中も「空中＋容器内＝投入量」を維持する。
- 水深が有限値であり、容器の高さを超えない。
- 注水終了後に波の振幅と運動エネルギーが減る。
- リセットで水面・空中の水・物理時間が初期化される。
- Metalの描画画像で、50%の水位と設定した不透明度を確認する。
- 背景の操作、停止・再開、画面サイズ変更、バックグラウンド復帰を確認する。
- 実機でCPU/GPU時間、フレーム間隔、発熱を測る。実機60fpsは未確認。

飛沫の追加に合わせ、注水角度−65°・0°・65°での水量保存、飛沫の再吸収、個数上限、リセットを自動テストする。Metalの描画テストには飛沫の描画も含める。注水開始直後・注水中・停止直後・末尾落下中・静止後の5時点を画像に保存して確認する。着水点のへこみ、注水後の圧力減衰、水流先端と水面の接続も自動テストで確認する。流量の増減、微量指定時の総量、入口断面が画面外にあることも検証する。合計13件が iPhone 18 Pro シミュレータで通過した。注水中の飛沫と静止後の水位の描画画像も確認した。見た目と操作感は引き続き実機・シミュレータで評価する。
